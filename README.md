# Khush Amrutiya — Engineering Portfolio

The personal portfolio and engineering showcase of **Khush Amrutiya**, Computer Engineering student at V.V.P. Engineering College, Rajkot.

## Featured Project

- **ORCA – Intelligent Ocean Risk & Coastal Analytics System**
  - **Category**: AI / Marine Intelligence / Full-Stack
  - **Context**: Smart India Hackathon 2026
  - **Overview**: An AI-powered marine intelligence and decision-support platform combining multi-agent AI, deterministic risk assessment, geospatial analysis, hazard awareness, and risk-aware route planning into a unified marine workspace.
  - **Live Demo**: [https://orca-in.vercel.app/](https://orca-in.vercel.app/)
  - **Project Video**: [https://youtu.be/WhbCpMSIlVU](https://youtu.be/WhbCpMSIlVU)

## Technical Architecture

- **Framework**: TanStack Start / React 19 / Vite
- **Language**: TypeScript
- **Styling**: Vanilla CSS with modern custom design system & Tailwind CSS
- **Primitives & Icons**: Radix UI Dialog, Lucide React
- **Hosting / Deployment**: Vercel
